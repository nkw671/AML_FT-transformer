## 성능지표<br>
RMSE / MAE: 만원 단위 오차<br>
MAPE: 평균 절대 백분율 오차<br>
R²: 결정계수<br>
허용 오차 정확도: ±5% / ±10% / ±20% 이내 비율<br>
(나중에 변경할 예정)
